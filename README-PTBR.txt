COMO USAR
1. Extraia este ZIP.
2. Copie as pastas "src" e "public" para:
   D:\Projetos\kill-lipe
3. Quando o Windows perguntar, escolha substituir os arquivos existentes.
4. Não apague seu arquivo .env.local.
5. No terminal do VS Code, rode:
   npm run build
6. Se o build passar:
   git add .
   git commit -m "feat: atualiza top 9 de coberturas e destaque recente"
   git push
